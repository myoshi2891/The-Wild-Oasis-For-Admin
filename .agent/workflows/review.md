# Code Review Workflow

## 手順

1. `git diff main` で変更差分を取得する
2. 以下の観点でコードレビューを実施:
   - **セキュリティ**: XSS 脆弱性、認証バイパス、API キーのハードコーディング
   - **パフォーマンス**: 不要な再レンダリング、React Query キャッシュ戦略、N+1 クエリ
   - **設計**: SRP の遵守、カスタムフックへの適切な抽出、styled-components の重複
   - **テスト**: エッジケースのカバレッジ、エラーハンドリングの網羅性
3. 問題があれば重大度（P0/P1/P2）付きでリストアップ
4. レビュー結果を Artifact（またはコメント/レポート）として出力し、未対応課題をそこに列挙する
5. 必要な場合は、未対応課題を含めた別PRやIssueでの対応をユーザーに提案する
