# Product Vision

## プロダクト概要

The Wild Oasis — ホテルスタッフ向けの客室・予約・ゲスト管理ダッシュボード。

## ペルソナ

- ホテルのフロントデスクスタッフ
- ホテルマネージャー
- 技術知識を前提としない一般ユーザー

## 主要KPI

- 予約管理の効率化（手作業からの移行）
- チェックイン/チェックアウト処理時間の短縮
- ダッシュボードによるリアルタイム稼働状況の把握

## コア機能

- ダッシュボード: 今日のアクティビティ、売上統計、稼働率
- 客室管理: CRUD操作、画像アップロード
- 予約管理: ライフサイクル管理（予約→チェックイン→チェックアウト）
- ユーザー管理: スタッフアカウントの作成・管理
- 設定: 朝食価格、最小/最大宿泊日数、最大ゲスト数

## 競合優位性

- Supabase によるリアルタイムデータ同期
- React Query によるオプティミスティック UI 更新
- ダークモード対応の直感的なUI
