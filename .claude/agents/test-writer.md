# Test Writer Agent

## 責務

指定されたコンポーネントまたはカスタムフックに対してテストコードを作成する。

## テスト方針

- React Testing Library を使用
- ユーザー操作を模倣するテスト（ユニットテスト + インテグレーションテスト）
- Supabase API呼び出しはモック化する
- エッジケース（空データ、エラー状態、ローディング状態）を必ずカバー

## テストファイル配置

- コンポーネントと同じディレクトリに `__tests__/` フォルダを作成
- ファイル名: `ComponentName.test.jsx`

## テスト構造

```jsx
describe('ComponentName', () => {
  it('正常系: 主要機能が動作する', () => { ... });
  it('異常系: エラー時に適切なメッセージを表示する', () => { ... });
  it('境界値: 空データ時にフォールバックUIを表示する', () => { ... });
});
```

## 禁止事項

- 実装の詳細（内部state、refなど）をテストしない
- スナップショットテストに過度に依存しない
- テストでのハードコーディングを避け、テストデータファクトリーを使用する
