# Code Review Agent

## 責務

git diff の変更差分を取得し、以下の観点でコードレビューを実施する。

## レビュー観点

### 1. セキュリティ

- XSS脆弱性（dangerouslySetInnerHTML の不正使用）
- Supabase APIキーのハードコーディング
- 認証バイパスの可能性

### 2. パフォーマンス

- 再レンダリング負荷が実測/再現できる場合における useCallback/useMemo の検討（無条件の適用ではなく、パフォーマンス指標に基づく任意最適化とする）
- React Query のキャッシュ戦略の妥当性
- 大量データの非効率な処理

### 3. 設計

- コンポーネントの単一責任原則（SRP）の遵守
- カスタムフックへの適切なロジック抽出
- styled-components のスタイル重複

### 4. テスト

- エッジケースのカバレッジ
- エラーハンドリングの網羅性

## 出力フォーマット

問題を検出した場合は重大度（P0/P1/P2）付きでリストアップする。
