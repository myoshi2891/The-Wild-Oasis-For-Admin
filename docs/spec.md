# The Wild Oasis 仕様書

## 概要

ホテルスタッフが客室、予約、ゲスト、および日々の業務を管理するための React ベースのホテル管理ダッシュボードアプリケーション。
ホテルの内部スタッフのみが使用し、ゲスト向けインターフェースは含まない。

## 主要機能

### 認証

- スタッフのログイン / ログアウト
- 新規スタッフアカウント作成（既存スタッフのみ可能）
- パスワード / アバター画像の更新

### ダッシュボード

- 今日のチェックイン / チェックアウト一覧
- 統計サマリー（売上、稼働率、チェックイン数）
- 売上チャート（直近 7 / 30 / 90 日）
- 滞在期間の分布チャート

### 客室管理

- 客室一覧（テーブル表示、ソート / フィルタ対応）
- 客室の作成 / 編集 / 削除 / 複製
- 客室画像のアップロード
- 割引価格の設定

### 予約管理

- 予約一覧（テーブル表示、ソート / フィルタ / ページネーション対応）
- 予約詳細の表示
- 予約ステータスのフィルタリング（未確認 / チェックイン済 / チェックアウト済）
- 予約の削除

### チェックイン / チェックアウト

- チェックイン処理（支払い確認、朝食オプション追加）
- チェックアウト処理
- 今日のアクティビティリスト

### 設定

- 朝食価格の設定
- 最小 / 最大宿泊日数の設定
- 最大ゲスト数の設定

## 非機能要件（制約）

- レスポンシブ対応（デスクトップ優先）
- ダークモード / ライトモード切替
- Supabase をバックエンドとして使用（自前 API サーバーは立てない）
- 認証済みユーザーのみがアクセス可能（ProtectedRoute）
- TypeScript strict モードによる型安全性の担保
- Vitest + Testing Library によるユニット / コンポーネントテスト基盤

| react-hook-form v7 | フォーム管理 |
| recharts v2 | データ可視化（チャート） |

| react-hot-toast | トースト通知 |
| react-icons | アイコン |
| react-error-boundary | エラーバウンダリ |
| TypeScript ~5.9 | 静的型検査 |
| Vitest ~4.0 | ユニットテストフレームワーク |
| @testing-library/react ~16 | コンポーネントテスト |

- [x] ダッシュボードに今日のアクティビティと統計が表示される
- [x] 客室の CRUD 操作が正常に動作する
- [x] 予約一覧のフィルタ / ソート / ページネーションが動作する
- [x] チェックイン / チェックアウト処理が正常に完了する
- [x] ダークモード / ライトモードの切替が動作する
- [x] 設定の変更が永続化される
- [x] 全ソースコードが TypeScript（strict）に移行されている
- [x] ユニット / コンポーネントテスト基盤が導入されている
